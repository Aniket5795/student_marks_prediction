# Student Marks Prediction

## Project Overview

This project uses Machine Learning to predict student examination marks based on the number of hours studied.

## Objective

Build a Linear Regression model to understand the relationship between study hours and examination marks.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

## Project Structure

- data: Dataset files
- notebooks: Jupyter notebooks
- src: Python source code
- models: Trained models
- results: Generated outputs

## Current Status

Project initialized. Model development is pending.

## Model

The project uses Scikit-learn's Linear Regression.

## Features

- Student dataset creation
- Exploratory data analysis
- Train/test split
- Linear Regression training
- Marks prediction
- Model evaluation
- Regression visualization
- Model serialization
